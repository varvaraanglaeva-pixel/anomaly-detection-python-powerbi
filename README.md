# Поиск аномалий в продажах с помощью Python в Power BI

**Задача:** среди тысяч транзакций найти подозрительные операции — заказы с аномально высокими или низкими суммами, которые могут указывать на мошенничество, ошибки ввода или сбой системы. Вручную это нереально, нужен автоматический статистический метод.

**Данные:** датасет Superstore с Kaggle, более 10 000 транзакций. Столбцы: Order ID, Sales, Customer Name, даты, категории товаров.

**Метод:** правило 3-х сигм. Если значение выходит за пределы среднего ± 3 стандартных отклонения, оно считается статистической аномалией. Это классический метод обнаружения выбросов, который работает без обучения модели и без разметки данных.

## Что делает скрипт

```python
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt

df = dataset

mean = np.mean(df['Sales'])
std_dev = np.std(df['Sales'])

df['is_anomaly'] = np.where((df['Sales'] > (mean + 3 * std_dev)) | 
                            (df['Sales'] < (mean - 3 * std_dev)), 'Аномалия', 'Норма')

plt.figure(figsize=(10, 6))
plt.scatter(df.index, df['Sales'], c=df['is_anomaly'].map({'Норма': 'blue', 'Аномалия': 'red'}))
plt.title('Поиск аномалий в продажах (Правило 3-х сигм)')
plt.ylabel('Сумма продажи')
plt.xlabel('Номер строки')
plt.show()
 ````
Скрипт считает среднее и стандартное отклонение по столбцу Sales, помечает каждую строку как «Норма» или «Аномалия» и рисует scatter-plot: синие точки — обычные продажи, красные — выбросы.
### Данные
На графике видно, что подавляющее большинство заказов лежит в диапазоне 0–5000. Красные точки — это заказы с суммами от 7 000 до 23 000, которые статистически выбиваются из общего распределения.
В таблице справа — конкретные подозрительные заказы: Order ID, сумма Sales и имя клиента. Это готовый список для проверки службой безопасности или бухгалтерией.

### Что бы я предложила бизнесу
1. Настроить автоматический алерт: если сумма заказа превышает границу 3-х сигм, отправлять уведомление менеджеру или в отдел контроля.
2. Проверить красные точки из таблицы — часть из них может быть легитимными (крупные корпоративные заказы), часть — ошибками или мошенничеством.
3. Добавить в дашборд срез по категориям товаров: возможно, аномалии концентрируются в определённых категориях (например, в Electronics).
4. Использовать этот же подход для других метрик: аномальные скидки, аномальные возвраты, аномальная активность клиентов.
